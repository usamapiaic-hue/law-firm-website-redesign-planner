# Law Firm Website Redesign Planner

Redesigns usually start because the old site looks dated. They go wrong when the new site drops pages that were bringing calls, or launches without redirects. This planner keeps the parts that work while the design changes. Published by Legal Web Agency.

## Phase 1: Measure what you have

- Export the pages that get the most search traffic and leads.
- List the searches each important page ranks for.
- Note which forms and phone numbers produce enquiries.

## Phase 2: Decide what stays

| Page type | Usual decision |
|-----------|----------------|
| Practice pages with traffic | Keep the URL, improve the content |
| Thin or duplicate pages | Merge into a stronger page and redirect |
| Old news posts with no visits | Remove and redirect, or leave as is |
| Attorney bios | Keep URLs, update photos and details |

## Phase 3: Build and test

- Write content before design, so layouts fit real text.
- Test on phones first.
- Check every form, phone link and disclaimer.

## Phase 4: Launch and watch

- Turn on redirects on the day of launch.
- Watch Search Console for errors for at least a month.
- Compare leads with the same weeks before launch.
